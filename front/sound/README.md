# Звуки игр (`front/sound/`)

Звук каждой игры собирается из двух источников:

- **`common/`** — *повторяющиеся* звуки, одинаковые для всех игр. Лежат **в
  одном экземпляре** и подключаются каждой игрой из этой папки. Не дублировать
  их в папки игр.
- **`<код-игры>/`** — *уникальные* звуки конкретной игры: 4 звука выигрыша,
  2 фоновых трека (базовый / бонусный уровень) и специфические SFX темы.

Пути прописаны в `front/js/<код-игры>/sound.js` (у Amy's Fruit Farm — в
`front/js/sound.js`) через две константы: `COMMON = 'sound/common/'` и
`GAME = 'sound/<код-игры>/'`. Чтобы добавить звук — положите файл с ожидаемым
именем (см. ниже) в нужную папку. Отсутствующий файл не ломает игру: `playSfx`/
`playMusic` глотают ошибку загрузки, игра просто играет тише.

> Папка называется `common`, а **не** `_common`: GitHub Pages (Jekyll)
> игнорирует папки, начинающиеся с `_`, и звуки бы не раздавались.

## Повторяющиеся звуки — `common/`

| Файл | Ключ в коде | Назначение |
|------|-------------|------------|
| `Click_UI.mp3` | `click` | клик по UI-кнопке |
| `Click_button.opus` | — | альтернативный клик (пока не подключён) |
| `Popup-open.mp3` | `popupOpen` | открытие попапа |
| `Popup-close.mp3` | `popupClose` | закрытие попапа |
| `reel-start.mp3` | `spinStart` | старт спина |
| `Reel_stop_slot.mp3` | `reelStop` | остановка барабана |
| `REELS_final_stop.mp3` | `finalReelStop` | остановка последнего барабана |
| `REELS_anticipation.mp3` | `anticipation` | «предвкушение» перед крупным исходом |

## Уникальные звуки — `<код-игры>/`

Во всех играх одинаковые *имена* (расширение — по факту доставленного файла,
обычно `.mp3`, иногда `.wav`):

| Файл | Ключ | Назначение |
|------|------|------------|
| `WIN_Small.*` | `smallWin` | базовый выигрыш |
| `WIN_Big.*` | `bigWin` | Big Win |
| `WIN_Mega.*` | `megaWin` | Mega Win |
| `WIN_Epic.*` | `epicWin` | Epic Win |
| `BG_Base.mp3` | музыка `base` | фон базового уровня |
| `BG_Bonus.mp3` | музыка `bonus` | фон бонусного уровня |

Плюс SFX, специфичные для темы (примеры из существующих игр):
`SCATTER_win`, `WILD_Scale` + `WILD_Scale_wind` (wild-игры), `HOLD&WIN_Coin`,
`COIN_land`, `cascade-win` / `cascade-drop` / `bomb-explode` (каскадные игры).
Их точный список для игры — в её `sound.js`.
