# Sugar Galaxy — уникальные звуки

Повторяющиеся звуки берутся из `../common/` (см. `../README.md`).
Ключи — в `front/js/sugar-galaxy/sound.js`.

## Уже на месте

- `WIN_Small.mp3` — играет на **каждой** выигрышной комбинации
- `WIN_Big.mp3`, `WIN_Mega.mp3`, `WIN_Epic.mp3` — крупные выигрыши (попапы)
- `WIN_Boom.mp3` — взрыв элементов после комбинации (раз на шаг каскада)
- `Element_drop.mp3` — приземление элемента в ячейку (спин: 6× через 0.1 c; каскад: при схлопывании/дозасыпке)
- `bomb-explode.mp3` — взрыв бомбы, ровно через **0.9 c** после начала анимации бомбы
- `SPIN_Start.mp3` — старт спина, через 0.1 c после нажатия (тематический, переопределяет общий `reel-start`)
- `BG_Base.mp3` — музыка базового уровня
- `BG_Bonus.wav` — музыка бонусного уровня
