# Party of Goods — уникальные звуки

Повторяющиеся звуки берутся из `../common/` (см. `../README.md`).
Ключи — в `front/js/party-of-goods/sound.js`.

## Уже на месте

- `WIN_Small1.mp3` … `WIN_Small5.mp3` — **эскалирующий** звук выигрыша:
  1-я выигрышная комбинация в спине играет `WIN_Small1`, 2-я — `WIN_Small2`,
  … 5-я и дальше — всегда `WIN_Small5`. Счётчик сбрасывается каждый спин.
- `WIN_Big.mp3`, `WIN_Mega.mp3`, `WIN_Epic.mp3` — крупные выигрыши (попапы)
- `WIN_Boom.mp3` — взрыв элементов после комбинации (раз на шаг каскада)
- `Element_drop.mp3` — приземление элемента в ячейку (спин: 6× через 0.1 c на приземлении сетки; каскад: при схлопывании/дозасыпке)
- `bomb-explode.mp3` — взрыв бомбы (через 0.5 c после старта flash-анимации бомбы)
- `SPIN_Start.mp3` — старт спина, через 0.1 c после нажатия (тематический, переопределяет общий `reel-start`)
- `BG_Base.mp3`, `BG_Bonus.mp3` — музыка базового / бонусного уровня
