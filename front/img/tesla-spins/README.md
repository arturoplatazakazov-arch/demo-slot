# Tesla Spins — ассеты (3x3)

Слаг игры — `tesla-spins`. Пути зашиты в `front/js/tesla-spins/slot.js`
(`ASSET_ROOT`); при ЛЮБОЙ замене файла поднимать там `ASSET_VERSION`.

**Весь арт вырезан из одной картинки** `src/reference.jpg` (1280x623, концепт
от заказчика) — без нейросетей, PIL/numpy. Пересобрать:

    .venv/bin/python scripts/tesla_spins_art.py     # img/ + symbols/
    .venv/bin/python scripts/tesla_spins_spine.py   # spine/

## img/

| файл | что это |
|---|---|
| `scene.jpg`     | референс с перерисованными ПУСТЫМИ ячейками (Coons-патч из чистой ячейки лимона, вставлен во все девять) |
| `scene_ext.jpg` | то же + 260px неба сверху (место под логотип и портрет), 1280x883 |
| `cabinet.png`   | рама шкафа поверх лент: кроп сцены (309,22)-(976,600), ячейки прозрачные |
| `coil_l/r.png`  | катушки с виньеткой — портретная раскладка ставит их шкафу на плечи |
| `logo.png`      | TESLA (Rockwell Bold, полированная медь с фаской по карте высот) + неоновая плашка SPINS с молниями по бокам; блик и разряды поверх — CSS и tesla-fx.js |
| `cover.jpg`     | обложка каталога 900x470 (референс с символами + лого) |
| `cell.jpg`      | чистая панель ячейки (запас, игрой не используется) |

Геометрия ячеек (пиксели референса) — в `COLS`/`ROWS` скрипта и в
`--win-*`/`--c*-*` в `css/tesla-spins.css`. Ячейки нарисованы неровно (189/195/195
по ширине), поэтому у каждой колонки своя ширина и своё окно обрезки.

## symbols/

Девять символов из ячеек референса: разница с чистой панелью по яркости+цвету
(тень темнее и того же цвета — в маску не попадает), заливка дыр, апскейл x2.
`coin` (монета-молния, символ Hold & Win) — маска собрана из диска монеты + молнии, нарисованные дуги вокруг
выброшены и заменены чистым свечением (живые дуги — в Spine и tesla-fx.js).

## spine/

Скелеты Spine 4.1, сгенерированы кодом поверх `scripts/spine_screen_kit.py`
(PMA-атласы). У символов клип `win` (1.9с: удар молнии сверху, рентген-кадры электрошока с тряской, две ударные волны, лучи, дуги по контуру, баллистические искры; начинается и кончается в setup-позе
= статика, слот `item` = PNG символа), у `coin` ещё `idle`. `zap` — FX без символа
(клип `hit`): удар в ячейку, куда в раунде упала монета.

## coins/

Лица монет раунда Hold & Win, нарисованы с нуля тем же metal()-шейдером, что
лого: `face.png` (медь, пустое поле — номинал ×N печатает клиент) и
`mini/minor/major/grand.png` (цвет тира, надпись запечена; `grand` на поле не
выпадает — он только за 9/9, монета для показа).
