# Multi Fruits Story — заметки по арту

Всё в этой папке пришло из мастера-конструктора (builder draft
"multi-fruits-story"), кроме одного производного изменения ниже.

## bell/animation.json — win-таймлайн собран вручную

Экспорт `bell` приехал вообще без блока `animations`: скелет, кости, слоты,
скин и атлас на месте, а таймлайна в файле нет — символ просто не с чем было
анимировать (у всех остальных символов есть `win`, у scatter/wild ещё
`idle`/`landing`).

Пока не пришёл нормальный ре-экспорт, в файл вклеен `win` из `diamond`:

* риги совпадают — те же кости `root`, `diamond`…`diamond9`, `bone`
  (у bell есть ещё `bone2` под язычок) и те же слои бликов
  `blik_bolshoi` / `blik_heart2_png*`;
* собственные части колокольчика (`hp_bell`, `verh` на `diamond2`,
  `hp_bell_molotolk` на `bone2` — потомок `diamond2`) висят на костях,
  которые этот таймлайн и крутит, поэтому анимируется весь символ;
* выброшен единственный слот-таймлайн, которого в риге bell нет —
  `hp_diamond_blik_1` (это собственный блик алмаза).

Чего в результате НЕ хватает: язычок (`hp_bell_molotolk`) отдельно не
качается — своей ключевой анимации у него нет, он просто едет вместе с
колокольчиком.

**Как откатить:** удалить из `bell/animation.json` ключ `"animations"` — файл
вернётся ровно к тому, что прислал художник. Настоящий ре-экспорт с живым
`win` просто кладётся поверх папки и затирает эту вклейку.
