# Gold of Baku — ассеты (3x3)

Слаг игры — `gold-of-baku`. Пути отсюда зашиты в
`front/js/gold-of-baku/slot.js` (`ASSET_ROOT`), при ЛЮБОЙ замене файла
поднимать там `ASSET_VERSION` — статика раздаётся без Cache-Control, и браузер
покажет старую картинку.

Все PNG квантованы на месте (256 цветов, FASTOCTREE) — 2.2 МБ → 469 КБ.
Не-квантованные оригиналы лежат в `src/`, перерисуешь что-то — квантуй заново.

## img/

| файл | что это | размер |
|---|---|---|
| `bg_base.jpg`     | фон десктоп: Пламенные башни, мечеть, ковёр | 1797x875 |
| `bg_base_mob.jpg` | фон портрет (v2: Девичья башня; исходник `src/bg_mob_raw_v2.jpg`) | 931x1690 |
| `cabinet.png`     | золотая рама с орнаментом, проём прозрачный | 1479x870 |
| `logo.png`        | логотип, обрезан по содержимому | 1400x410 |
| `cover.jpg`       | обложка каталога (собрана из фона + рамы + символов + лого) | 900x470 |

**Ковровая полка под рамой восстановлена вручную.** Присланный `frame.png` с
альфой обрывался на y=836: вырезатель фона съел нижнюю орнаментальную панель.
Она вернулась из версии на чёрном (`src/frame_on_black.png`) — мягкий ключ по
луме в альфу, цвет разделён на альфу (снятие премультипликации), и полоса
вклеена в `frame.png` от y=836 вниз. `src/frame_cut.png` — присланный вариант
как есть.

**Проём снят с альфы `cabinet.png`** заливкой изнутри и живёт в CSS долями
картинки: окно 171..1308 по X и 61..751 по Y, то есть
`--win-l 0.1156 / --win-t 0.0701 / --win-w 0.7694 / --win-h 0.7943`. Из них
считается и позиция барабанов, и размер ячейки (1.65 — ячейка шире, чем выше).
Перерисуешь раму — пересними доли, на глаз не подгоняй.

## symbols/

Семь символов, обрезаны вплотную по содержимому (вписываются в ячейку
`object-fit: contain`, оптический вес правится через `--sym` в CSS):
`orange`, `grape`, `pomegranate`, `tea`, `bell`, `bar`, `seven`.

Имена файлов — контракт с `_SYMBOLS` в `app/seed/gold_of_baku.py` и
`SYMBOL_CODES` в `slot.js`: код символа == имя PNG. Не переименовывать.
`tea` — это стаканы армуды (прислано как `shashki.png`), `pomegranate` — гранат.
