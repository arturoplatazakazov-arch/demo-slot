# Gold of Baku 2 — ассеты (3x3)

Синий рескин `gold-of-baku`: механика, символьные коды и вёрстка те же, меняется
только арт. Слаг игры — `gold-of-baku-2`. Пути отсюда зашиты в
`front/js/gold-of-baku-2/slot.js` (`ASSET_ROOT`), при ЛЮБОЙ замене файла
поднимать там `ASSET_VERSION` — статика раздаётся без Cache-Control, и браузер
покажет старую картинку. То же и с `?v=` в `front/gold-of-baku-2.html`
(фон, рама и логотип подставлены прямо в разметке).

## Синий арт (заменён 20.08.2026)

Синими приехали фон (ландшафт + портрет), рама, логотип, `seven`, `bar` и
`tea`. Из золотой версии остались как есть `symbols/orange.png`,
`symbols/grape.png`, `symbols/pomegranate.png`, `symbols/bell.png` — синих
вариантов этих четырёх не было. `img/cover.jpg` пересобрана из нового арта
(скрипт-композиция: фон → сукно → рама → 3x3 символов → логотип).

Сукно барабана и палитра в `front/css/gold-of-baku-2.css` перекрашены из бордо
в тёмную синь (`--carpet/--carpet-deep/--ink`, градиент `.reel`), иначе проём
читался красной дырой в синей раме.

**Доли проёма пересняты с новой рамы** заливкой изнутри (не сканом строк: скан
протекает через зазор между нижним брусом и ковровой полкой и выдаёт окно до
низа картинки). `cabinet.png` = 1565x864, пропорция 1.811, окно 175..1391 по X
и 73..749 по Y, то есть `--win-l 0.1118 / --win-t 0.0845 / --win-w 0.7776 /
--win-h 0.7836`. От пропорции 1.811 считается и `--cab-h` в обоих режимах
(десктоп 1300→718, портрет 950→524). Перерисуешь раму — пересними доли и
пересчитай `--cab-h`, на глаз не подгоняй.

**Сверяй bbox альфы присланной рамки с версией «на чёрном».** У золотой версии
вырезатель фона съел нижнюю ковровую панель (альфа обрывалась на y=836); у этой
рамы панель на месте, но проверять надо каждый раз.

Все PNG квантованы на месте (256 цветов, FASTOCTREE). Не-квантованные исходники
как пришли — в `src/*_blue_raw.png` (папка в `.gitignore`).

## symbols/

Семь символов, обрезаны вплотную по содержимому (вписываются в ячейку
`object-fit: contain`, оптический вес правится через `--sym` в CSS):
`orange`, `grape`, `pomegranate`, `tea`, `bell`, `bar`, `seven`.

Имена файлов — контракт с `_SYMBOLS` в `app/seed/gold_of_baku_2.py` и
`SYMBOL_CODES` в `slot.js`: код символа == имя PNG. Не переименовывать.
`tea` — это стаканы армуды, `pomegranate` — гранат.
