# Ice Spin Deluxe — ассеты (3x3)

Слаг игры — `ice-spin-deluxe`. Пути отсюда зашиты в
`front/js/ice-spin-deluxe/slot.js` (`ASSET_ROOT`), при ЛЮБОЙ замене файла
поднимать там `ASSET_VERSION` — статика раздаётся без Cache-Control, и браузер
покажет старую картинку.

## img/

| файл | что это | размер |
|---|---|---|
| `bg_base.jpg`     | фон десктоп | 1536x1024 |
| `bg_base_mob.jpg` | фон портрет | 941x1672 |
| `cabinet.png`     | ледяная рама, три проёма прозрачные | 1672x941 |
| `logo.png`        | логотип, обрезан по содержимому | 1637x528 |
| `cover.jpg`       | обложка каталога (собрана скриптом из фона + рамы + символов + лого) | 900x470 |

**Проёмы рамы сняты с альфы `cabinet.png`** и живут в CSS долями картинки:
окна по X — 269..608, 665..1003, 1060..1398, по Y — 180..877, то есть
`--win-l 0.1609 / --win-t 0.1913 / --win-w 0.6758 / --win-h 0.7418` и перемычка
`--win-gap 4.87%`. Из них считается и позиция барабанов, и размер ячейки.
Перерисуешь раму — пересними доли, на глаз не подгоняй.

## symbols/

Девять символов, обрезаны вплотную по содержимому (вписываются в ячейку
`object-fit: contain`, оптический вес тира правится через `--sym` в CSS):
`cherry`, `plum`, `lemon`, `orange`, `grape`, `bell`, `star`, `bar`, `seven`.

Имена файлов — контракт с `_SYMBOLS` в `app/seed/ice_spin_deluxe.py` и
`SYMBOL_CODES` в `slot.js`: код символа == имя PNG. Не переименовывать.
